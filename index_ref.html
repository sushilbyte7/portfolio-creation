The challenge

A recurring internal workflow required hours of repetitive manual work each month. The goal was to reduce that effort with a reliable web application while keeping people in control of the result.

My approach

  1. Gather requirements

    Collected requirements and clarified the repetitive manual work the application needed to address.

  2. Design the solution

    Translated those requirements into a practical web application, with a clear approach to automating the recurring work.

  3. Build the application

    Implemented the application using Python and Django with a MySQL database, taking the requirements through to a working solution.

  4. Deploy

    Deployed the application on a Hostinger VPS so the team could use it in their everyday work.

The team moved from hours of manual processing to a workflow completed in minutes, freeing time for review and decisions.
